AGVPN

Неофициальный графический клиент AdGuard VPN для Linux (Flatpak, x86_64 и aarch64).

Установка

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user @URL@/agvpn.flatpakref

Или откройте agvpn.flatpakref в GNOME Software / KDE Discover.

Обновление

flatpak update

Запуск и удаление

flatpak run io.github.agvpn.AGVPN
flatpak uninstall --user io.github.agvpn.AGVPN

Исходники и подробная инструкция: github.com/Pager-290583/agvpn.
