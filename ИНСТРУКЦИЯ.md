# AGVPN: установка на другой компьютер с Linux

Подходит любой дистрибутив с Flatpak: Fedora, Ubuntu, Debian, Arch, openSUSE, Mint и другие.
Есть два способа:

- **Способ А** — установить готовую сборку с GitHub одной командой. Быстро, ничего собирать
  не нужно, подходит и для x86_64, и для ARM (aarch64).
- **Способ Б** — собрать пакет из исходников на самом компьютере. Нужен, если нет доступа
  к GitHub или вы меняли код и хотите проверить его до отправки.

---

## 0. Подготовка (для обоих способов)

### Установить Flatpak

| Дистрибутив | Команда |
|---|---|
| Fedora | уже установлен |
| Ubuntu / Debian / Mint | `sudo apt install flatpak` |
| Arch / Manjaro | `sudo pacman -S flatpak` |
| openSUSE | `sudo zypper install flatpak` |

После первой установки Flatpak **перезайдите в систему** (выйдите из сеанса и войдите снова),
чтобы приложение появилось в меню.

### Подключить Flathub

```sh
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
```

### Что нужно в системе для работы VPN

- `pkexec` (polkit) или `sudo` — есть почти везде;
- модуль ядра `tun`; если при подключении приложение пишет, что TUN недоступен:
  `sudo modprobe tun`;
- для Kill Switch — `nft` (nftables): `sudo apt install nftables` / `sudo dnf install nftables`.

## Способ А. Готовая сборка с GitHub

При каждом изменении кода GitHub сам собирает приложение и выкладывает его в Flatpak-репозиторий
на https://pager-290583.github.io/agvpn/ (там же эта команда и дата последней сборки).

```sh
flatpak install --user https://pager-290583.github.io/agvpn/agvpn.flatpakref
```

На вопросы отвечайте `y`. Среда GNOME 50 скачается с Flathub (≈ 400 МБ при первой установке),
а официальный AdGuard VPN CLI — с GitHub AdGuard. Целостность CLI проверяется по SHA-256.

Запустите «AGVPN» из меню приложений или командой:

```sh
flatpak run io.github.agvpn.AGVPN
```

Отдельного файла `.flatpak` нет: такой файл не умеет скачивать AdGuard CLI при установке
и не ставится (ошибка «Дополнительные данные отсутствуют в отдельных метаданных»).

## Способ Б. Сборка из исходников

### 1. Получить исходники

Проект лежит на Яндекс.Диске в папке **`adguard-rs`**:

- если на компьютере установлен клиент Яндекс.Диска, папка уже есть: `~/Yandex.Disk/adguard-rs`;
- с GitHub: `git clone https://github.com/Pager-290583/agvpn.git ~/adguard-rs`;
- если клиента нет, скачайте из веб-интерфейса Яндекс.Диска архив `adguard-rs/agvpn-rs-src.tar.gz`
  и распакуйте его:

  ```sh
  tar -xzf agvpn-rs-src.tar.gz -C ~      # появится папка ~/adguard-rs
  ```

### 2. Собрать и установить

```sh
cd ~/Yandex.Disk/adguard-rs      # или ~/adguard-rs, если распаковывали архив
./build.sh
```

Временные файлы сборки (около 2 ГБ) скрипт кладёт в `~/.cache/agvpn-rs`, а не в папку проекта,
поэтому на Яндекс.Диск они не попадают.

Скрипт сам:

1. подключит Flathub и, если в системе нет `flatpak-builder`, поставит его из Flathub
   (`org.flatpak.Builder`);
2. скачает GNOME SDK 50 и компилятор Rust (`org.freedesktop.Sdk.Extension.rust-stable`) —
   ставить Rust в систему **не нужно**;
3. скачает все библиотеки Rust по списку `flatpak/cargo-sources.json` и проверит их контрольные суммы;
4. соберёт приложение, прогонит тесты и установит его.

Первая сборка занимает 10–20 минут и скачивает около 1,5 ГБ, повторные идут быстрее.

Для `build.sh` нужен `python3`, но только если менялся `Cargo.lock`: тогда скрипт
пересобирает `flatpak/cargo-sources.json`. Python есть практически во всех дистрибутивах.

## После установки

1. При первом запуске пройдите приветственные экраны и примите соглашения.
2. Войдите в аккаунт AdGuard через браузер или по почте и паролю (поддерживается 2FA).
3. Нажмите «Подключить». Система спросит пароль администратора: VPN-сервису нужны права root.
   Чтобы пароль больше не спрашивался: **Настройки → Расширенные настройки →
   «Подключаться без пароля»** (ставит помощник в `/usr/local/libexec/agvpn`).

Значок в трее работает в KDE, Cinnamon, XFCE и waybar. В GNOME нужно расширение
**AppIndicator and KStatusNotifierItem Support**.

## Обновление

- **Способ А:** `flatpak update` — новая сборка придёт сама вместе с остальными приложениями.
- **Способ Б:** замените исходники и снова запустите `./build.sh`.

Настройки, вход в аккаунт и статистика при обновлении сохраняются.

## Удаление

```sh
flatpak uninstall --user io.github.agvpn.AGVPN
flatpak uninstall --user --unused                 # неиспользуемые среды выполнения
rm -rf ~/.var/app/io.github.agvpn.AGVPN           # данные и настройки (по желанию)
```

Если включали «Подключаться без пароля», сначала выключите эту опцию в приложении.
Либо удалите помощник вручную:

```sh
sudo rm -rf /usr/local/libexec/agvpn /etc/sudoers.d/io-github-agvpn \
            /etc/polkit-1/rules.d/49-io.github.agvpn.AGVPN.rules
```

## Если что-то не работает

| Проблема | Решение |
|---|---|
| Приложения нет в меню | Перезайдите в систему после установки Flatpak |
| «TUN device is not available» | `sudo modprobe tun` |
| Kill Switch не включается | Установите `nftables` |
| Не появляется окно ввода пароля | Приложение спросит пароль само (через `sudo`) — введите пароль своего пользователя |
| Нужны логи | Настройки → Поддержка → «Экспорт логов и сведений о системе» |
